# Changelog

All notable changes to the ZAK Icons ecosystem are documented here.

## [1.0.0] - 2026-09-09

### Initial Release
- **Icon Library**: 300+ pixel-perfect vector SVG icons built on a 24×24 grid with 2px default stroke.
- **Logistics & Enterprise Suite**: Comprehensive coverage for logistics, supply chain, freight, maritime, warehousing, and operations.
- **Multi-Platform Support**:
  - `@zak-icons/core`: Shared metadata, types, and raw icon data.
  - `@zak-icons/react`: Tree-shakeable React components with full TypeScript props.
  - `@zak-icons/blazor`: Native .NET Razor components for Blazor Server & WebAssembly.
  - `@zak-icons/flutter`: Flutter Dart package supporting customizable sizes, colors, and opacity.
  - `@zak-icons/web`: Native Web Components (`<zak-icon>`) for any HTML/JS framework.
- **Showcase & Docs Web App**:
  - Interactive Icon Browser with sub-millisecond Fuse.js client search and keyboard shortcuts.
  - Live Icon Detail Customizer with size, stroke width, rotation, and color options.
  - Multi-Framework Playground with real-time live code previews.
  - Curated Collections for UI, Logistics, DevOps, AI, Finance, and Security.
  - Full developer documentation for SVG, React, Blazor, Flutter, and Web Components.
